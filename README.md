# Study Quest v2.0 — 公開用アプリファイル

このフォルダには、GitHub Pagesで公開できるStudy Questのコードと、PWA用の設定・アイコンが入っています。**実際の試験名、受験日、生活予定、学習履歴などの個人データは含んでいません。** アプリに登録した情報は、原則として各端末のブラウザ内の `localStorage` に保存します。クラウドへの自動送信は実装していません。

## iPhoneでGitHubへアップロード

1. ZIPをダウンロードし、「ファイル」で解凍する。
2. Safariで `https://github.com/ayahakie/study-quest` を開き、リポジトリの最上位を表示する。
3. `Add file` → `Upload files` を選ぶ。見つからないときはSafariの「デスクトップ用Webサイトを表示」を利用する。
4. 解凍した `Study-Quest-v2.0` **フォルダの中の9ファイル**をすべて選ぶ。ZIPやフォルダそのものは選ばない。
5. `Commit changes` → `Commit directly to the main branch` → `Commit changes` で更新する。
6. 数分後、`https://ayahakie.github.io/study-quest/?v=20` を開いて確認する。古いホーム画面アプリのアイコンが更新されない場合は、必要に応じて新しいアイコンを追加する。削除前にはバックアップを取る。

アップロードする9ファイル:

- `index.html` — 画面
- `app.css` — レスポンシブデザイン
- `app.js` — 学習・計画・分析などの機能
- `manifest.webmanifest` — PWA設定
- `sw.js` — オフライン表示用のキャッシュ管理
- `icon-180.png` — iPhoneのホーム画面用
- `icon-192.png` — アプリアイコン
- `icon-512.png` — アプリアイコン
- `README.md` — この説明書

**重要:** ファイルはすべて既存の `index.html` と同じ階層へ置いてください。`Study-Quest-v2.0/index.html` のような別フォルダを作るとトップページが更新されません。

## 実装されている主な機能

### ホーム
- XP、レベル、コイン、称号、学習時間、連続学習、復習待ち、日替わりミッション
- 7日間の学習時間棒グラフ、近日の試験、優先科目候補
- 「帰宅した」「夕食中」「夕食が終わった」「今日は休む」の生活状況入力と時刻修正

### 学習
- ポモドーロ（初期値：集中25分、短い休憩5分、4回ごとに長い休憩15分）、時間のカスタマイズ
- ストップウォッチ、停止・再開・手動終了、実時間に基づく計測
- タイマー学習終了時のみ休憩を提案。**手動入力では休憩を尋ねない**
- 試験・科目・分野・教材、問題数、正解数、進捗、メモ付きの学習記録
- XP・コイン獲得、学習記録の削除、間違えた問題から復習予定を作成

### 計画
- 週表示・月表示のカレンダー、日付切り替え、試験と予定の表示
- 予定の登録・編集・削除、毎日・平日・毎週・毎月の繰り返し
- 睡眠・仕事・食事・移動・自由時間、時間が変わりやすい予定への対応
- 60分のBuffer（編集可）、Buffer Day、仕事のない日、通常・忙しい・休養モード
- 生活予定が不足する場合は「学習可能時間は未確定」、実績不足なら「必要学習量は算出待ち」と表示
- 教材の残量、所要時間の実績、試験までの残り日数から暫定的な必要学習時間を算出
- 週・月の暫定必要量、時間不足の警告、空き時間帯の候補（生活予定がそろった場合）
- 試験・共通科目・分野・教材の登録、編集、削除。科目は複数の試験で共有可能
- 教材の単位（講義／ページ／問題／章など）、登録時の既習量、実績進捗、所要時間を管理

### 分析
- 今日・直近7日・30日・3か月・6か月・1年・全期間
- 試験・科目別フィルタ、学習時間と正答率の推移、科目別学習、苦手分野
- 教材の進捗、必要学習量との差、復習予定と完了状況
- 模試・本試験の点数と推移、初回問題と復習問題の区別
- **共有科目の学習記録は全体集計で二重計上しない**

### 報酬
- 初期ごほうびとカスタムごほうびの追加・編集・削除、長押し・管理モード
- コイン交換と交換履歴、XP/レベルの独立管理
- 実績・称号の獲得、称号の装備

### 設定・データ保護
- アプリを開いたときの学習・試験・復習・ミッションのお知らせ
- JSONで全データを書き出し、CSVで学習記録を書き出し
- JSON復元の内容プレビュー、復元前バックアップ、二段階の初期化
- 旧バージョンv1の保存データを**ユーザー操作でのみ**移行
- 暗黙的な旧データ引き継ぎはせず、新しい保存領域 `studyquest_v2` を使う

## 現在の制約

- **合格保証はできません。** 必要学習時間の数値は、教材情報と観測された進捗・所要時間に依存する暫定見積もりです。登録情報が不足していれば、推測で「毎日40分」などの値は表示しません。
- 生活予定が不足している場合、空き時間を勝手に「学習可能時間」と見なしません。入力されていない移動・休息等は計算できません。
- iPhoneでアプリを閉じている間のプッシュ通知、アカウント間・クラウド同期、外部カレンダーとの自動同期には対応していません。
- 端末を削除・初期化するとローカルデータも失われ得ます。定期的なJSONバックアップを推奨します。
- ブラウザの保存領域はSafari版とホーム画面版で分離される場合があります。データ移行が必要なときはJSONを使ってください。
- iPhoneのSafari/WebKit実機での最終表示・操作確認は、インストール後に行ってください。開発中の自動テストではモバイル幅のChromiumを使用しています。

## 動作確認

- 試験、共有科目、教材の登録と進捗記録
- 手動学習記録、誤答から復習予定生成、XP獲得
- 生活予定の繰り返し登録と学習可能時間の推定
- ポモドーロ終了後の休憩表示
- JSON書き出し→初期化→内容プレビュー→バックアップ→復元
